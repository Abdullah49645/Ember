Data Sources
Methodology

Ember couples a heuristic wildfire propagation model with a live evacuation routing engine. It is a decision-support simulation for exploring how environment and infrastructure interact — not an operational wildfire forecast.

Real inputs (this build)

Live: wind, temperature and humidity come from Open-Meteo, and active-fire detections (VIIRS, last 24 h) come from NASA FIRMS through EMBER's own server, which holds the API key. Cached / procedural: terrain elevation (USGS 3DEP), land cover (ESA WorldCover) and the road network (OpenStreetMap) are deterministic stand-ins shaped like typical values from each source. Every source is labeled LIVE or CACHED in the Data Sources panel; if a live request fails or returns nothing, EMBER falls back to its cached scenario and says so — cached data is never presented as live telemetry. Swapping the remaining stand-ins for the real sources would not touch the simulation engine.

Model

Cellular fire propagation on a grid, factoring fuel (land cover), wind alignment, slope, humidity-driven dryness, and temperature. Probabilistic downwind spot ignition. User-deployed firebreaks locally suppress spread.

Decision engine

Roads are classified SAFE / WATCH / THREATENED / BLOCKED from projected fire proximity. A graph router (Dijkstra) recomputes least-risk evacuation paths whenever road status changes, penalizing threatened edges and excluding blocked ones.
